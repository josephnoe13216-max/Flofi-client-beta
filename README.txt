FLOFI CLIENT para Minecraft Java 1.21.4 (Fabric)

OPCION A - sin instalar nada (GitHub genera el .jar):
1. Crea una cuenta en github.com y un repositorio nuevo (privado esta bien).
2. Sube TODO el contenido de esta carpeta (incluida .github, src, build.gradle...).
3. Pestana "Actions" -> espera a que termine "build" (3-5 min).
4. Entra a esa ejecucion -> abajo en "Artifacts" descarga FlofiClient-jar.
5. Descomprime: dentro esta floficlient-1.0.0.jar.

OPCION B - en tu PC: instala Java 21 + Gradle 8.12 y ejecuta "gradle build".
El jar queda en build/libs/.

INSTALAR: Fabric Loader 1.21.4 (fabricmc.net/use) + Fabric API 1.21.4 (modrinth.com/mod/fabric-api)
y pon floficlient-1.0.0.jar y fabric-api.jar en .minecraft/mods.
